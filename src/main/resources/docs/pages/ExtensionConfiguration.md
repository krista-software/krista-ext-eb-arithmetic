# Configuration

EB Arithmetic has **no Setup-tab fields**. Every request is computed locally inside the extension —
there is no external system, API key, or connection string to configure. Installing the extension
is the only setup step required; it is ready to use immediately.

## Required vs optional

Not applicable — there are no configuration fields.

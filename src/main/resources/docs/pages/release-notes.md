## v1.0.0 (October 2026)

Initial release — a sample, self-contained arithmetic extension with no external dependencies.

### New Features
* Add, Subtract, Multiply, and Divide requests, each taking two numbers and returning the result.
* Standard Setup area (Test Connection, Health Check) adapted for a no-external-system extension —
  both verify the extension's own arithmetic logic rather than network/credential connectivity.

# Overview

EB Arithmetic adds basic arithmetic to Krista workflows and agents — addition and subtraction of two
numbers — computed entirely inside the extension. It does not call any external system, so no
credentials or network access are required.

## Use cases

- **Add two numbers** — compute the sum of two numbers supplied by a workflow or agent.
- **Subtract two numbers** — compute the difference of two numbers supplied by a workflow or agent.

## What you can do

The extension exposes 4 requests grouped by area — see
[Supported Requests](pages/supported-requests.md) for the full list, or the sidebar for each
request's detailed page.

## Before you start

1. No credentials are required — see [Authentication](pages/Authentication.md).
2. There is nothing to configure — see [Configuration](pages/ExtensionConfiguration.md).
3. Run **Test Connection** (Setup area) to confirm the extension is loaded.

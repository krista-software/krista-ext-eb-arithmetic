# Configuration

EB Arithmetic has **no Setup-tab fields** to configure. It performs every calculation locally and
never connects to an external system, so there is no base URL, API key, or token to supply.

## Setup tab fields

| Field | Required | Default | Description |
|-------|----------|---------|-------------|
| _(none)_ | — | — | This extension has no connection configuration. |

## Required vs optional

Not applicable — there are no fields to validate or save.

## Notes

- Installing the extension is the only setup step; it is ready to use immediately once the jar is
  deployed and bound to the EB Playground / EB Testing domain.

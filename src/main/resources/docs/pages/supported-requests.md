# Supported Requests

EB Arithmetic exposes **4 catalog requests** across **2 areas**. Each links to its detailed page.

## Setup
| Request | Type | Description |
|---|---|---|
| [Test Connection](pages/TestConnection.md) | QUERY_SYSTEM | Verifies the extension is loaded and ready. |
| [Health Check](pages/HealthCheck.md) | CHANGE_SYSTEM | Reports extension and JVM health. |

## Calculator
| Request | Type | Description |
|---|---|---|
| [Add Two Numbers](pages/AddTwoNumbers.md) | QUERY_SYSTEM | Adds Number1 and Number2 and returns their sum. |
| [Subtract Two Numbers](pages/SubtractTwoNumbers.md) | QUERY_SYSTEM | Subtracts Number2 from Number1 and returns the difference. |
